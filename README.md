# BITQUEST — The Digital Business Challenge

A lightweight, single-player booth game for BINUS Business Information Technology (BIT). Players complete five business decision challenges and earn BIT Coins.

## Deploy to Vercel

1. Import this GitHub repository into Vercel.
2. Set Framework Preset to **Other**.
3. Leave Build Command empty.
4. Set Output Directory to `.`.
5. Deploy.

This is a static HTML/CSS/JavaScript project. No build step or environment variables are required.

## Notes

- Designed for a quick 4–5 minute single-player booth experience.
- BIT Coins and scores are held in browser memory only; there is no shared leaderboard or database.
